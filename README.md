=# 🌐 Tanzanite Skills Academy – Landing Page

Welcome to the official **Tanzanite Skills Academy** landing page, built using **React** and **Tailwind CSS**. This website aims to showcase the services offered by the academy with a modern, clean, and mobile-friendly layout.

---

## 🚀 Features

- 🎨 Beautiful hero section with gradient background and large typography
- 🖼️ Auto-sliding image carousel (slider)
- 📋 List of services offered
- 📞 Contact details section
- ✅ Fully responsive (Mobile First)
- ⚡ Fast and lightweight

---
